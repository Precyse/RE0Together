# CODEMAP: re0

Resident Evil 0 HD: the x86 adapter and its one-PC fake peer. Index and "where to look for X": `CODEMAP.md`.

## adapters/re0/ (C++20, x86, dinput8.dll proxy)

Build (from a VsDevCmd x86 shell): `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build`. Output `build/dinput8.dll`, copied to `adapters/re0/dinput8.dll`. Unit tests (no game): every `build/*_test.exe` except `net_test` (needs a launcher) exits 0 and prints its pass line. Vendored MinHook in `third_party/minhook` (wrapped by src/hooks.cpp) and Dear ImGui (imgui core + `backends/imgui_impl_dx9`, MIT) in `third_party/imgui`.

## tools/re0/fake_peer/ (Python, stdlib only; `python tools\re0\fake_peer <command>`)

One-PC fake peer for RE0 state mode: plays the second machine (guest with the game as host, or host with the game as guest) on the same PC, speaks the whole state protocol, emulates the peer half of every flow, and checks the game's half from `adapter.log`. Commands: `list`, `run <scenario> [--seat guest|host] [--scratch] ...`, `gates <scenario>`, `library build`, `golden`, `selftest [--smoke]`. Runs write `<game>\coop\fake_peer\<stamp>-<scenario>\` (frames.jsonl, launcher logs, adapter segment, report.txt / report.json). Design, coverage and limits: `docs/RE0_NOTES.md` "State mode: one-PC fake peer"; commands per scenario: `adapters/re0/README.md` "One-PC state tests with the fake peer".
