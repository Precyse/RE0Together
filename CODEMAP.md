# CODEMAP

Spec: `docs/CONTRACT.md`. Tools: `tools/save_sync_test.py` (two local launchers, checks the save transfer and the reset), `tools/fake_adapter.py` (fake game adapter), `tools/echo_peer.py` (echoes 0x0100/0x0101 frames back after a delay; see `adapters/re0/README.md`), `tools/spoof_peer.py` (sends a wrong slot byte over local transport), `tools/diagnostics_test.py` (guest log lines and a crash dump reach the host), `tools/build_check_test.py` (mismatched builds refuse, matching ones carry on). RE0 research tools in `tools/re0/`: `gamectl.py` (keys and screenshots to the game window only, refuses unless RE0 is in front; `idle` = seconds since the user last used mouse/keyboard), `probe.py`, `disasm.py`, `watch_write.py`, `fake_session.py` (stand-in launcher with a scripted peer: doors, rooms, party mode, placements, a join snapshot with `--guest`; tests split rooms and rejoining on one PC), `party_state.py` (both characters' room record, scene, in-room flag, position), `enemies.py` (live enemies of the loaded room: pool slot, class, HP, position), `dump_stack.py` (registers and return addresses of a `coop\crash-*.dmp`). DS2 research tools in `tools/ds2/` (static ones read `DS2.exe` straight from disk; output goes to the git-ignored `tools/ds2/out/`): `rtti_scan.py` (Decima reflection: types, bases, fields with offsets, message handlers present in the file), `disasm.py` (x64 disassembly, xrefs, string users, MSVC RTTI vtables), `symbols.py` (script-exported function name to address), `probe.py` (read-only live reads: instances of a class (`--near` = only the heap holding an address, seconds instead of minutes), pointer refs, annotated dumps, entity transforms, `handlers <Type>` from the live reflection records), `save_sync_test.py` (DS2 save sync on local transport with temp folders: manifest, every *.dat into the guest's session Documents, reset), `fake_launcher.py` (stand-in launcher on the adapter port with a scripted peer: stands, walks a circle, reports driving a vehicle for a time window; the real launchers are not needed), `fake_peer.py` (scripted second player: walks a circle around the local player, PLAYER_STATE at 60 Hz; `--cargo` plays a guest's backpack for the give/take menu (`--pickup` asks the host to confirm a pickup), `--host` plays a host (`--host-give` takes the guest's first piece and gives one, `--pickup-answers` accepts or refuses pickups in turn, `--host-pickup` reports a host pickup), `--drop` reports a drop (`here` = next to the local player), drops received are printed, `--drive ID` drives a vehicle along the circle (`--drive-load` reports its bed, `--drive-window` limits the drive to a time window), the vehicle the game drives and its load are printed), `gamectl.py` (DS2 window via `tools/re0/gamectl.py` (the largest DS2.exe window: the start-up launcher can stay visible), plus the shared game-window lock, `launch`, `close` and relative `mouse` motion for the camera). `tools/publish_check.py` gates pushes and releases.

## Where to look for

- GUI: `launcher/Gui/MainForm.cs`; session logic stays in `App.cs`
- Auto-update or release packaging: `Updater.cs`, `.github/workflows/release.yml`
- Wire format or control messages: `Framing.cs`, `ControlMessages.cs`
- Slot / epoch rules: `Session.cs`, `SlotAssigner.cs`
- Adapter link behaviour: `LoopbackBridge.cs`
- Add a game: new `launcher/games/<id>.json` (DS2: `ds2.json`, adapter `adapters/ds2`, notes `docs/DS2_NOTES.md`, stages `docs/DS2_ROADMAP.md`)
- Native `steam_api64.dll` (Valve-signed redistributable from the Steamworks.NET 2024.8.0 standalone release, SDK 1.60): `launcher/native/`
- Items (inventory blocks): `inventory_sync.cpp`; floor items: `floor_items_sync.cpp`; layouts in `docs/RE0_NOTES.md` Items
- RE0 game addresses: `adapters/re0/src/game.h` (source: `docs/RE0_NOTES.md`)
- Save sync: `SaveSyncCoordinator.cs` (launcher), `save_redirect.cpp` (adapter)
- Guest logs on the host: `LogForwarder.cs`, written to `<game>\coop\peer_<steamid>.log`
- Adapter network behaviour: `adapters/re0/src/net_client.cpp`
- Control rule (who drives a character): `control_rule.h` (pure) applied in `character_owner::controlOf`; party commands: `command_input.cpp`, `party_mode.cpp`, `camera_parity.cpp` (trace a press or decision in `adapter.log`, lines starting `command:`); pickup crash guard: `pickup_guard.cpp`
- Overlay contents: `adapters/re0/src/debug_lines.cpp` (add a stat: counter/gauge in `debug_stats.h`, update it where the event happens, add a line)
- Reverse-engineering patterns shared across games: `docs/re/PATTERNS.md` (grown by the `coop-re` skill)
- Before pushing: `python tools/publish_check.py` (no game files, dumps, decompiled output or keys; also runs in the release workflow)
- Players in different rooms / independent play: `adapters/re0/src/split_rooms.cpp` (moving a character between rooms: `scene.cpp`), camera rule in `camera_parity.cpp`, control rule in `control_rule.h`; test on one PC with `tools/re0/fake_session.py`
- Tuning input delay without a partner: `adapters/re0/build/trace_replay.exe --synthetic 120 --jitter 60`, or record with `net_trace=1` and replay the file
- A crash on a player's machine: `coop\crash-*.dmp` next to adapter.log, read with `tools/re0/dump_stack.py`
