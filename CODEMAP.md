# CODEMAP

Spec: `docs/CONTRACT.md`. This file is the index: which file holds the table of an area, the release files and "where to look for X". Each area file lists every source file once (file, what it owns, key members); read only the area you work in. Update the area file in the same change that adds, moves or renames a file or a key function.

| area | file | covers |
|---|---|---|
| launcher | `docs/codemap/launcher.md` | `launcher/` core, `launcher/Ui/` view models, `launcher/WebHost/` (WebView2 window), `launcher/web/` (the page) |

## release/ (repo root)

| file | owns |
|---|---|
| .github/workflows/release.yml | on push to `main` (channel `latest`) or `next` (channel `next`, prerelease): `publish_check.py`, `release_manifest_test.py`, build the RE0 and SR2 adapters (x86) and the DS2 adapter (x64) with their unit tests, the launcher end-to-end tests, assemble the package (`launcher\app`, `launcher\games\*.json`, `adapters\re0\dinput8.dll`, `adapters\sr2\dinput8.dll` + `scripts.delta.json` (fails when missing), `adapters\ds2\version.dll`, `README.txt`), download the channel's current `manifest.json` and component zips (before the release is replaced; none yet = everything new), run `tools/release_manifest.py` (a component whose built files have the previous release's paths and SHA-256 ships the previous zip unchanged with its version, any other is the new build with previous version + 1; writes `update.json` {repo, channel} and `installed.json` {build, channel, commit, components}, zips `Coop.zip`, `launcher.zip`, `mod-<id>.zip`, `manifest.json`; on `latest` also `RE0-Coop.zip` for launchers released before the manifest), update the release tagged with the channel in place (assets uploaded with `--clobber`, assets no longer produced deleted, title `Build <run number>` and notes updated, created when missing; never deleted, so a failed step cannot leave the channel without a release), manifest uploaded last, then the tag moved to the build commit (a failure to move it is only a warning) |
| launcher/package/README.txt | player README shipped in the package |
| launcher/update.json | `{ "repo": "Precyse/RE0Together", "channel": "preview" }` copied next to the exe; a missing file or the `OWNER/REPO` placeholder disables updating (the release build writes the real repo and channel into the package) |
