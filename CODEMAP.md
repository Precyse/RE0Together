# CODEMAP

Spec: `docs/CONTRACT.md`. Tools: `tools/save_sync_test.py` (two local launchers, checks the save transfer and the reset), `tools/fake_adapter.py` (fake game adapter), `tools/echo_peer.py` (echoes 0x0100/0x0101 and the pose puppet's 0x0140/0x0141/0x0142 frames back after a delay; see `adapters/re0/README.md`), `tools/spoof_peer.py` (sends a wrong slot byte over local transport), `tools/diagnostics_test.py` (guest log lines and a crash dump reach the host), `tools/build_check_test.py` (mismatched builds, game builds and mod files refuse, matching ones carry on), `tools/peer_link_test.py` (`--gap S`: a fake guest goes silent for S seconds against a host launcher with `fake_adapter.py`, S=5 is held and comes back as a second PEER_UP, S=15 is PEER_DOWN; `--flood N`: N unreliable 0x0100 frames a second show a `Peer budget:` line and the link stays up), `tools/launcher_tests/` (C# console unit tests for the pure launcher rules: mod content hash, BUILD_INFO comparison, member grace, token buckets, fresh-frame queue; `dotnet run --project tools/launcher_tests`). RE0 research tools in `tools/re0/`: `gamectl.py` (keys and screenshots to the game window only, refuses unless RE0 is in front; `idle` = seconds since the user last used mouse/keyboard), `probe.py`, `disasm.py`, `watch_write.py`, `fake_session.py` (stand-in launcher with a scripted peer: doors (with the door target and flags in ROOM_STATE, so a door barrier wait can be seen), rooms, party mode, placements, a join snapshot with `--guest`; prints the game's room script events (EVENT_START, EVENT_STEPS) and APPEARANCE, `appearance <billy|rebecca> <hex>` sends one, `--fake-character` swaps the fake's character; tests split rooms and rejoining on one PC), `party_state.py` (both characters' room record, scene, in-room flag, position), `enemies.py` (live enemies of the loaded room: pool slot, class, HP, position), `dump_stack.py` (registers and return addresses of a `coop\crash-*.dmp`). DS2 research tools in `tools/ds2/` (static ones read `DS2.exe` straight from disk; output goes to the git-ignored `tools/ds2/out/`): `rtti_scan.py` (Decima reflection: types, bases, fields with offsets, message handlers present in the file), `disasm.py` (x64 disassembly, xrefs, string users, MSVC RTTI vtables), `symbols.py` (script-exported function name to address), `probe.py` (read-only live reads: instances of a class (`--near` = only the heap holding an address, seconds instead of minutes), pointer refs, annotated dumps, entity transforms, `handlers <Type>` from the live reflection records), `save_sync_test.py` (DS2 save sync on local transport with temp folders: manifest, every *.dat into the guest's session Documents, reset), `fake_launcher.py` (stand-in launcher on the adapter port with a scripted peer: stands, walks a circle, reports driving a vehicle for a time window; `--echo-weapon` plays Sam's WEAPON_STATE / WEAPON_FIRE back as the peer's; `--cutscene` plays a cutscene host (START, GO on READY, END) with `--guest`, or a guest that answers READY, and prints every cutscene message; the real launchers are not needed), `fake_peer.py` (scripted second player: walks a circle around the local player, PLAYER_STATE at 60 Hz; `--cargo` plays a guest's backpack for the give/take menu (`--pickup` asks the host to confirm a pickup), `--host` plays a host (`--host-give` takes the guest's first piece and gives one, `--pickup-answers` accepts or refuses pickups in turn, `--host-pickup` reports a host pickup), `--drop` reports a drop (`here` = next to the local player), drops received are printed, `--drive ID` drives a vehicle along the circle (`--drive-load` reports its bed, `--drive-window` limits the drive to a time window), the vehicle the game drives and its load are printed), `gamectl.py` (DS2 window via `tools/re0/gamectl.py` (the largest DS2.exe window: the start-up launcher can stay visible), plus the shared game-window lock, `launch`, `close` and relative `mouse` motion for the camera). `tools/publish_check.py` gates pushes and releases.
