Co-op

Start launcher\app\coop-launcher.exe. One package holds the launcher and the mod for every game.

Each game in the list shows its mod: Not installed, Installed (Build N) or Update available (Build M).
Pick a game and use the button next to Host: Install, Update or Uninstall (the game must be closed).
Host and Join need the mod installed and a game version the mod supports (Game build N unsupported). Both players need the same game version.
If the game closes or crashes during a session, Relaunch starts it again and it catches up. If the game was started outside the launcher the status reads Game not linked: close it and start it from the launcher.

Host: pick the game, click Host, then send the lobby code (or click Invite).
Join: paste the lobby code and click Join.
Both players need the same build; the launcher refuses a mismatch.
The Update button (top bar) installs a newer package; close the launcher, open it again, then Update the game's mod.
The Settings button (top bar) sets each game's folder (when Steam does not find it), turns the update check at start on or off, opens the logs folder and creates a report zip (launcher log and each game's coop logs) to send when something goes wrong.
Only one launcher window runs at a time; starting it again brings the open one forward. If Steam is not running the launcher reads Offline and keeps retrying.
If the host's game or launcher crashes and the host starts again, the guest's launcher follows into the host's new lobby by itself. Closing the launcher during a session asks first; the game keeps running.

Resident Evil 0 HD: the host plays Rebecca, the guest plays Billy. The guest gets the host's save automatically.
Saves made during co-op always go to the last save slot (20), so your solo saves stay untouched.

In game (Resident Evil 0 HD)
  E / LT       Team (travel through doors together) / Split up (go anywhere on your own; the other
               player's doors never touch your screen). Each player always has their own camera.
  F8           status panel; Page Up / Page Down scroll it

The launcher checks for updates when it starts (Settings can turn that off).
