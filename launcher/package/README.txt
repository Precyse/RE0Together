Co-op

Start launcher\app\coop-launcher.exe. One package holds the launcher and the mod for every game.

Each game in the list shows its mod: Not installed, Installed (Build N) or Update available (Build M).
Pick a game and use the button next to Host: Install, Update or Uninstall (the game must be closed).
Host and Join need the mod installed.

Host: pick the game, click Host, then send the lobby code (or click Invite).
Join: paste the lobby code and click Join.
Both players need the same build; the launcher refuses a mismatch.
The Update button (top bar) installs a newer package; then Update the game's mod.

Resident Evil 0 HD: the host plays Rebecca, the guest plays Billy. The guest gets the host's save automatically.
Saves made during co-op always go to the last save slot (20), so your solo saves stay untouched.

In game (Resident Evil 0 HD)
  E / LT       Team (travel through doors together) / Split up (go anywhere on your own; the other
               player's doors never touch your screen). Each player always has their own camera.
  F8           status panel; Page Up / Page Down scroll it

The launcher checks for updates when it starts.
