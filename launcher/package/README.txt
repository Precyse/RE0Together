Co-op

Start launcher\app\coop-launcher.exe. One package holds the launcher and the mod for every game.

Each game in the list shows its mod: Not installed, Mod N, Mod update M or Mod modified.
Pick a game and use the button next to Host: Install, Update or Repair (the game must be closed). Uninstall is in Settings, in the game's section.
The mod button installs every file the game needs (Saints Row 2 also gets its coop\scripts folder); nothing has to be sent or copied separately. An update also removes files the new mod no longer uses. Your own files in the way are kept as .cfbak and put back by Uninstall.
Host and Join need the mod installed and a game version the mod supports (Game build N unsupported). Both players need the same game version.
If the game closes or crashes during a session, Relaunch starts it again and it catches up. If the game was started outside the launcher the status reads Game not linked: close it and start it from the launcher.

Host: pick the game, click Host, then send the lobby code (the clipboard icon copies it).
Join: paste the lobby code into Lobby code and click Join. Friends who are hosting appear under the Host row with their own Join.
Both players need the same build; the launcher refuses a mismatch.
The Update to N button (top bar) installs a newer package; when it reads Restart, click it, then Update the game's mod.
The Settings button (top bar) sets each game's folder (when Steam does not find it), uninstalls a game's mod, turns the update check at start on or off, opens the logs folder and creates a report zip (launcher log and each game's coop logs) to send when something goes wrong.
Only one launcher window runs at a time; starting it again brings the open one forward. If Steam is not running the launcher reads Steam not running and keeps retrying.
If the host's game or launcher crashes and the host starts again, the guest's launcher follows into the host's new lobby by itself. Closing the launcher during a session asks first; the game keeps running.

Resident Evil 0 HD: the host plays Rebecca, the guest plays Billy. The guest gets the host's save automatically.
Saves made during co-op always go to the last save slot (20), so your solo saves stay untouched.

In game (Resident Evil 0 HD)
  E / LT       Team (travel through doors together) / Split up (go anywhere on your own; the other
               player's doors never touch your screen). Each player always has their own camera.
  F8           status panel; Page Up / Page Down scroll it

The launcher checks for updates when it starts (Settings can turn that off).
